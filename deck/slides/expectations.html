Before we start

What you keep, and what you trade

Upside

What you gain

  • No API key and no bill, so it can run all night
  • Secure and Private
  • Your code never leaves the laptop
  • A harness small enough to hand edit
  • It works on a plane, in the woods, or under the sea
  • It is yours to change

Trade-off

What you give up

  • Speed: about 20 tokens a second in real agent turns (on a Macbook M3) 
  • "Medium" Reasoning trims that down to 10/sec
  • Build Your Own safety: pi has no permission prompts or sandbox out of the box
  • 200k Context Window

Treat it like a capable junior on a slow connection: clear tasks, tests to check against, and a fence around it.

No. 02

Let me set expectations, because the comparison you will make is with Claude Code on a frontier model. What you gain is real: no key, no bill, so you can leave it running overnight; your code stays on the laptop; and the harness is small enough to read in an afternoon, so you understand what it is doing. What you give up is also real. Speed: in real agent turns my setup writes about twenty tokens a second, and it reads long prompts slowly. Judgement: a 27B model is good at well-scoped tasks and weaker at long, many-step ones. Safety: Claude Code ships with permission prompts and a sandbox; pi ships with neither, so you build them. And time. The rest of this talk is how I closed as much of that gap as I could. The mental model that works for me: a capable junior on a slow connection. Give it clear tasks, tests to check its own work, and a fence.

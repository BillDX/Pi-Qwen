And here is everything on one page, for anyone who wants to copy it. The machine is an M3 Max MacBook Pro with 96 gigabytes. The model is Qwen3.8-27B on MTPLX, 4-bit, drafting three tokens ahead, with LM Studio's MLX 4-bit as the fallback. Pi's context is capped at 131 thousand tokens and output at about 33 thousand, thinking on medium, and compaction at pi's defaults. Pi itself is version 1.3.0, with the sandbox and MTPLX packages pinned to exact versions, the built-in MCP, codemode and tool-search extensions turned off because I do not use them and MCP servers would run outside the sandbox, four small guard extensions, three skills, four prompt templates and an AGENTS.md of about three hundred tokens. The boundaries: the sandbox denies all of /Users and allows the project back, blocks twenty-two kinds of write, and allows eight domains. The guards confirm rm -rf and sudo and protect .env and .git, a git stash is taken every turn, and a project's own sandbox.json is only read once I trust the project. Every one of these files, and the tests behind them, is in the write-up; ask me for the link.

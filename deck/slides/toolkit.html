Here is what I actually keep. A global AGENTS.md of about three hundred tokens: work only in the project; no sudo, no pushing, no reading .env files; if a guard or the sandbox blocks you, stop and say so rather than looking for a way round; use uv, never pip; keep a PLAN.md current so work survives compaction; and run the tests and linter, then commit, after each step. Four prompt templates, which cost nothing until typed: review the uncommitted diff without editing; write a plan and stop for approval; hand off by updating PLAN.md and committing it; and fix the first failing test by finding the cause first. Three skills from the superpowers collection, which the model loads when it needs them, and four small guard extensions. And in each project, a few lines with the exact commands. If you only do one thing for a small model, give it the exact test command. It guesses less, and everything on the next few slides depends on it.

Here is the honest side-by-side. Before your task even starts, pi sends about two thousand tokens and four tools; the HarnessTax study measured Claude Code at about twenty-seven thousand and twenty-three tools. Anthropic does not publish that number, so treat it as one study's measurement. Pi talks to any OpenAI-compatible server, which is the whole reason it works with a local model; Claude Code runs Claude models only, and its docs say it does not support routing to other models. Safety is the big difference: Claude Code has six permission modes including plan and auto, allow, ask and deny rules, protected paths, and a bash sandbox you switch on with slash sandbox. Pi has none of that built in. Undo: Claude Code has rewind checkpoints, which do not cover changes made through bash; pi has a session tree and fork, and I lean on git for the code. Plan mode, a task list and subagents are built into Claude Code; in pi you use a plan file, templates and extensions. And extending pi means writing TypeScript against the same API the built-in tools use. Pi gives you a small, fast core and expects you to add the rest.

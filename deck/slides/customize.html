No. 12

Pi is built to be bent, and people have. Eight worth a look. pi-subagents adds the subagents pi leaves out: scout, reviewer and worker sessions you can run in parallel; about seventy thousand downloads a week. pi-mcp-adapter puts MCP behind one small proxy tool so servers do not bloat the prompt, and starts them only when used. pi-lens runs language-server diagnostics, linters and type checks after every edit, which is exactly the kind of automatic feedback a small model benefits from; it is the one I want to try next. Plannotator opens the agent's plans and diffs in a browser so you can annotate them line by line. Three ship with pi as examples: jev-router, a virtual model where a strong model plans and a cheap one edits, which is a neat template for local-plus-hosted; handoff, which starts a fresh, focused session instead of compacting; and gondolin, which runs pi's tools in a QEMU micro-VM. And Armin Ronacher's own kit, with tricks like sessions that message each other. The README's real advice is to ask pi to build what you want; it can write an extension, hot-reload it and test it. There is also DOOM. The trade-off is the same as everywhere in this talk: over five and a half thousand packages, none reviewed, all running with your full permissions. Pin versions and read the source.

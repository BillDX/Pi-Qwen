Start here

If you want to try this, here is an evening's worth. Install LM Studio and download Qwen3.8-27B in the MLX 4-bit build, about sixteen gigabytes. Install pi, either with its install script or with npm, pinned and with ignore-scripts, and add LM Studio as a provider in models.json; it is one small block. Install pi-sandbox at a pinned version and start from my sandbox config, which is in the write-up. Write a short AGENTS.md and copy the four prompt templates. Then pick a small repository of your own whose tests pass today, make a clone, and try the loop: slash plan, read and approve the plan, then slash fix-tests or a small feature. MTPLX for speed and the skills for discipline can come later; neither is needed on day one.

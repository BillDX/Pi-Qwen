No. 13

Four tricks I use, and every screenshot here is from a real session on this setup: the local model planning and writing a FizzBuzz with tests, then a second attempt from the same starting point. Biggest first: slash export writes the whole session as one HTML file. You get the session tree with every branch, every tool call with its arguments and output, token counts, and even pi's complete system prompt and tool list, which is a nice way to see for yourself how small the harness is. Slash share uploads it and gives you a link. Slash tree is the same tree inside the terminal: jump back to any step, try a different approach, and both branches stay, so you can compare. The to-do example adds a tool the model uses to plan, and slash todos shows its list; the state follows your branches. And because a local model gives you time on your hands: pi ships Snake, Space Invaders and even DOOM as example extensions, and a title-bar spinner so you can tell from another tab when it is done. All of these are one dash e flag away, from the examples folder that comes with pi.

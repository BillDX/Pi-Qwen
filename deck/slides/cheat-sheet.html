Getting started

Cheat sheet: zero to a local agent

1

Install the MTPLX app · mtplx.com/download

Its fan control adds a passwordless sudo rule. Remove it:

sudo rm /etc/sudoers.d/mtplx-thermalforge

2

Download the model (20 GB) and serve it

mtplx pull Youssofal/Qwen3.8-27B-MTPLX-Optimized-Speed

mtplx quickstart --port 8000

3

Install pi (Node 22.19+) · github.com/earendil-works/pi

npm install -g --ignore-scripts \

  @earendil-works/pi-coding-agent@1.3.0

4

Add the sandbox and the MTPLX bridge, pinned

pi install npm:pi-sandbox@0.7.2

pi install npm:pi-mtplx@0.2.0

5

Register the model, restart, then work

pi, then /mtplx → Models, then /quit

cd my-repo && pi, then /model → mtplx

Agents: in AGENTS.md

Run the tests and linter before a step is done

Keep PLAN.md current; commit each step

Blocked by the sandbox? Stop and say so

System: in pi’s settings

"defaultThinkingLevel": "medium"

"contextWindow": 131072

"extensions": ["-builtin:mcp"]

Skills: in ~/.agents/skills

test-driven-development

verification-before-completion

systematic-debugging

No. 02

Here is the whole setup on one page, in the order I would do it. One: install the MTPLX Mac app from mtplx.com. It sets up its own Python engine and puts the mtplx command on your path. It also installs fan control with a passwordless sudo rule, which lets anything running as you become root, so remove that rule with the command shown. Two: download Qwen3.8-27B in MTPLX's Optimized-Speed build, about twenty gigabytes, and start the server on port 8000; the app can do both for you too. Three: install pi from npm, pinned, with ignore-scripts as its README says; it needs Node 22.19 or newer. Four: add pi-sandbox and pi-mtplx, both pinned. Five: start pi, register the model through slash mtplx, Models, quit and restart pi, then in your repository pick the model with slash model. Then the three things worth setting up first. In AGENTS.md: make the model run the tests and linter before it calls a step done, keep a PLAN.md and commit each step, and stop when the sandbox blocks it rather than look for a way round. In pi's settings: thinking on medium, the context window capped at 131 thousand in models.json, and the built-in MCP extension off, because MCP servers run outside the sandbox. And three skills from the superpowers collection: test-driven development, verification before completion and systematic debugging, copied into dot-agents slash skills. All of these were tested on pi 1.3.0 and MTPLX 2.12 in October 2026.
